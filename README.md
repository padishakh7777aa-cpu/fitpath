# FitPath — Telegram Mini App

Статическое приложение (HTML/CSS/JS, без сборки). Уровни: Новичок / Продвинутый / Про.
Разделы: план тренировок, анимированная техника (9 упражнений), калькулятор питания, спортпит, здоровье.

## Запуск в Telegram
1. Залей папку на любой HTTPS-хостинг (GitHub Pages, Netlify, Vercel, Cloudflare Pages).
2. В @BotFather: `/newapp` (или `/setmenubutton`) → укажи свой бота и URL приложения.
3. Открой бота → кнопка меню → приложение.

Локально: `python3 -m http.server 8000` и открой http://localhost:8000.
