# LIGHTWEIGHT — Telegram Mini App

Тренировки, питание, механика и биохакинг в Telegram. Статическое приложение (HTML/CSS/JS), без сборки.
Неофициальный проект в духе легенды бодибилдинга; не связан с Ронни Коулманом.

## Возможности
- 3 уровня (Новичок / Продвинутый / Про), подбор программы по цели и дням в неделю, 11 программ.
- **Тренировка с гидом**: приложение ведёт по шагам (3D-анимация, подсказанный вес и повторы, таймер отдыха, отметка «тяжело/норм/легко», авто-прогрессия). Есть ручной режим и свободная тренировка.
- Недели программы и напоминание о разгрузке, «Сегодня по плану».
- 17 упражнений в 3D (three.js): реалистичный персонаж (Mixamo, GLB), штанга, скамья, турник, блок. Вращение пальцем, подсветка мышц.
- Механика роста, биомеханика упражнений, биохакинг (чек готовности, протокол дня, анализы, добавки по уровню доказательности).
- Питание: калькулятор КБЖУ и готовое меню. Инструменты: 1ПМ, блины, RPE. Прогресс: графики веса, силы, тоннажа.
- Данные сохраняются на устройстве и в облаке Telegram (CloudStorage).
- Без схем и дозировок гормональных препаратов: только риски, анализы и безопасность.

## Структура
- `index.html`, `style.css`, `app.js`, `app2.js` — интерфейс и логика.
- `data.js`, `programs.js`, `knowledge.js` — упражнения, программы, знания.
- `anim.js` (2D), `anim3d.js` (3D-атлет), `anim3d_mx.js` (реалистичный персонаж и риг).
- `models/` — `character.glb`, анимации Mixamo (FBX), `manifest.json`.
- `tools_convert_character.py` — конвертация персонажа Mixamo в лёгкий GLB (Blender `bpy`).
- `guide.js` — тренировка с гидом (шаги, вес, отдых, прогрессия).
- `app2.js` — экраны: Сегодня, меню, прогресс, достижения, О приложении.
- `sw.js` — service worker: кэш для быстрых повторных запусков и работы без сети.
- `tests/` — автопроверки (см. `tests/README.md`).
- `bot/` — Telegram-бот (кнопка приложения, команды, напоминания).

## Запуск
1. Опубликуй папку на HTTPS (GitHub Pages: Settings → Pages → ветка → root).
2. @BotFather → `/newapp` или `/setmenubutton` → URL приложения.
3. Бот: см. `bot/README.md` (нужен сервер и токен).

## Как сменить персонажа / добавить анимации
1. Скачай модель из Mixamo (FBX Binary, With Skin, T-pose) и анимации (Without Skin).
2. Запусти конвертацию: `python tools_convert_character.py -- '{"squat":"squat.fbx", ...}'` (нужен `pip install bpy`).
3. Положи `character.glb` в `models/` и впиши имена клипов в `models/manifest.json`.
Упражнения без клипа анимируются расчётными позами на том же скелете.

## Производительность и надёжность
- Тяжёлый 3D-движок (three.js) и персонаж грузятся лениво, в фоне после первого экрана.
- Service worker кэширует файлы: повторные запуски быстрые, приложение открывается и без сети.
- Если 3D недоступно (старый телефон, нет WebGL), показывается 2D-анимация. На слабых устройствах качество снижается автоматически.
- При ошибке показывается понятный экран с возвратом на главный, данные не теряются.

## Релиз нового обновления
Увеличь номер `?v=N` у скриптов в `index.html` (и версию `APP_VERSION` в `app.js` при необходимости). Запусти автопроверки из `tests/`.

## Показатели
- Первый экран: ~70 КБ (gzip), без 3D. 3D-движок (~200 КБ) и персонаж (~2 МБ) подгружаются в фоне и кэшируются.
- Доступность: аудит axe-core (WCAG 2 A/AA) без нарушений; контраст основного текста 17,6:1, вспомогательного не ниже 6,2:1.
- Автопроверки: 48 тренировочных дней, 630 экранов, 6 тестов бота.
